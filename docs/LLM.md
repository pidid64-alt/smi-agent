# Подключение LLM

LLM **необязательна**: без неё система мониторит, оценивает, отбирает и проверяет темы, а на этапе текста выдаёт честную **заготовку для редактора** (целые предложения из проверенных фактов с атрибуцией). Заготовка не проходит проверку оригинальности, пока вы не перепишете её, и никогда не публикуется автопилотом.

## Настройка
```env
SMI_LLM_PROVIDER=openai_compat     # openai_compat | anthropic | none
SMI_LLM_BASE_URL=https://api.openai.com/v1   # любой OpenAI-совместимый endpoint (vLLM, Ollama, gateway…)
SMI_LLM_API_KEY=…                  # секрет окружения
SMI_LLM_MODEL=…                    # название модели (не задано по умолчанию намеренно: выберите под ru/kk/en)
SMI_LLM_DAILY_CALL_BUDGET=2000
```
* `openai_compat` — `POST {base}/chat/completions` (режим `response_format=json_object`); `anthropic` — Messages API (`x-api-key`, `anthropic-version: 2023-06-01`). Оба клиента написаны по публичной документации и проверены на подменённом транспорте; **с живыми провайдерами не запускались**.
* В production для LLM по HTTP допускаются только `localhost` (остальное — HTTPS).
* Бюджет вызовов в сутки (`llm_calls`); при исчерпании — эвристика. Каждый вызов журналируется (задача, модель, токены, задержка, статус; без текста запроса).

## Что отправляется модели
Только **база фактов** (проверенные факты с признаком «нужна атрибуция», цитаты с авторами, даты, число источников, названия источников, неизвестное) и бриф (язык, тон, угол, акцент, объём). Полные тексты статей, секреты, данные пользователей и профиль не отправляются. Внешний текст оборачивается в `<source_material>…</source_material>` с экранированием `<`/`>`, а системная инструкция требует считать его **данными, а не командами**.

## Защита от плохих ответов (`content/generator.py::validate_generated`)
Ответ отклоняется (и заменяется заготовкой, причина пишется в `draft.notes`), если: есть число, которого нет в базе фактов (допуск 1%; производные числа вроде разности отклоняются); есть цитата из ≥4 слов, которой нет в базе (названия в «ёлочках» цитатами не считаются); есть ссылка вне списка источников; язык не совпал; есть агитационные формулировки; общая с источником фраза ≥10 слов или >12% общих 5-грамм; <2 пунктов. Для каждой платформы — отдельный вызов и те же проверки.

## Поведение при сбоях
Нет ключа/ошибка сети/невалидный JSON/нарушение схемы/бюджет исчерпан → `None` → эвристика. Вызов LLM **внутри транзакции записи запрещён** (исключение) — генерация идёт между короткими транзакциями.

## Демо-«LLM»
В `SMI_DEMO_MODE=1` подключается `DemoLlm` — **не языковая модель**, а набор заранее написанных оригинальных текстов для вымышленных демо-новостей; на любые другие события она не отвечает (работает заготовка). Её ответы проходят те же проверки, что и ответы настоящей модели. В production она не подключается.

## Добавить провайдера
Реализуйте класс с методом `complete(system, user, *, max_tokens, temperature, json_mode) -> LlmResult` и зарегистрируйте его в `llm/client.py::build_client`. Остальное (бюджет, журнал, строгий JSON, проверки) общее.
